# SIL2.2_Frontend
Frontend website for SIL2.2

## Workflow

1. Make a branch

`git branch yv-example`

2. Go into the branch

`git checkout yv-example`

3. Add, Commit, Push in the branch

`git add .` 

`git commit -m "text"`

`git push`

4. Then copy the given commaned and enter.

`git push --set-upstream origin yv-example`

5. Go to github in the repositoty in the tab 'Pull requests'
